> UTTU.Gallery is the successor to [Reverse99-Index](https://github.com/Sleepless-index/Reverse-1999-index), rebuilt with an updated design and improved export formats.

## Features

- **Roster** — Add the characters you own, edit their levels, Resonance, and portraits, then export your roster as a clean, shareable image.
- **Teams** — Build teams using your roster, arrange character slots, choose between compact or detailed layouts, and export them as shareable images.
