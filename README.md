## ◈ Features

- **Roster Management**  
  Add the characters you own, edit their levels, Resonance, and portraits, then export your roster as a clean, shareable image.
  
- **Team Builder**  
  Build teams using your saved roster, arrange character slots, choose between compact or detailed layouts, and export them as high-quality, shareable images.
